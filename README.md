# Explaining the Return Differential Between U.S. and European Equity Markets

This study aims to analyze and model the monthly return differential between U.S. and European equity markets. The research investigates the extent to which the following factors explain the structural outperformance of U.S. equities since 2005:

- Interest rate differentials (Federal Reserve vs. European Central Bank)
- EUR/USD exchange rate movements
- Implied volatility differentials (VIX vs. VSTOXX)
- Sectoral composition differences (technology sector performance US vs. EU)

## Research Questions

- Which modeling approach best explains the US-EU equity return differential: simple linear regression, polynomial features, lagged variables, Lasso regularization, or Tree-based methods (Random Forest, Gradient Boosting)?
- Can non-linear models provide additional explanatory power on a limited time series dataset (240 observations)?
- Which features contribute most to model performance across different approaches?

## Methodology

1. **Data Collection** - Monthly data from multiple sources (Refinitiv, Capital IQ, FRED, iShares) covering 2005-2024
2. **Data Preprocessing** - Cleaning, percentage conversion, temporal alignment, handling missing values
3. **Feature Engineering** - Creation of dependent variable (Y) and explanatory variables (X1-X4) with lagged features, plus data standardization (StandardScaler) for regularized models
4. **Exploratory Analysis** - Summary statistics, correlation analysis, temporal coverage verification
5. **Model Development** - Linear models (simple regression, polynomial features, lagged variables), regularization (Lasso with cross-validation), and ensemble methods (Random Forest, Gradient Boosting)
6. **Model Evaluation** - Comparison using R², RMSE, MAE, AIC, BIC, and Adjusted R²
7. **Feature Importance** - Identification of key predictors across different modeling approaches
8. **Diagnostic Tests** - VIF for multicollinearity, residual analysis for linear models

## Data Description

### Dependent Variable

**Y: Return Differential**

Y_t = R_US,t - R_EU,t

- R_US,t: S&P 500 Total Return Index (SPXTR) monthly return
- R_EU,t: EuroStoxx 50 Gross Return Index (STOXX50GR) monthly return in USD

### Explanatory Variables

**X1: EUR/USD Exchange Rate Change**

X1_t = (FX_t / FX_t-1) - 1

- Source: Refinitiv
- Frequency: Monthly Close 

**X2: Monetary Policy Differential**

X2_t = i_t^Fed - i_t^ECB

- Fed Funds Effective Rate: FRED (FEDFUNDS)
- ECB Main Refinancing Rate: FRED and BCE
- Unit: Percentage points (direct difference, not returns)

**X3: Volatility Differential**

X3_t = VIX_t - VSTOXX_t

- VIX: FRED (VIXCLS)
- VSTOXX: Refinitiv (.V2TX)
- Calculation: Monthly average
- Unit: Annualized implied volatility (%)

**X4: Technology Sector Performance Differential**

X4_t = R_US_tech,t - R_EU_tech,t

- US Technology: XLK (Technology Select Sector SPDR) from Yahoo Finance
- EU Technology: iShares STOXX Europe 600 Technology (ISIN: DE000A0H08Q4)
- Based on monthly NAV total returns (dividends reinvested)

### Feature Importance Analysis

**Lasso (M3) - Selected Variables** (5/8 retained):
- X1 (EUR/USD change)
- X2 (Policy differential)
- X3 (Volatility differential)
- X4 (Tech sector differential)
- X3_lag1 (Volatility lag)

**Ensemble Methods (M4/M5) - Top Features**:
1. **X1 (EUR/USD)** - Dominant (~60%)
2. **X3 & X3_lag1** (Volatility) - Significant (~21-24%)
3. **X4** (Tech sector) - Modest (~10%)
4. **X2** (Policy) - Modest (~9%)

### Key Findings

- **Winner**: M2b (Linear Regression with Lagged Variables) - R² = 0.423
- **Temporal dynamics**: Lagged variables improve R² from 0.11 to 0.42 (4x improvement)
- **Most important predictor**: EUR/USD change (X1) is the dominant driver across all models
- **Regularization**: Lasso achieves best AIC/BIC scores, selecting 5/8 variables for optimal parsimony
- **Non-linear models**: Underperform on small dataset (240 observations) due to overfitting (0.66 train R² vs 0.09 test R²)
